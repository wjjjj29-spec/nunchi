What would you call Wonhee?

In Korean you don't use the name alone for someone older. If you are younger than Wonhee, a woman would say unnie (언니) and a man would say noona (누나). If you are older, Wonhee would be calling you that. Born the same year? You're 동갑 (dong-gap), and first names are fine.
