What would you call Giselle?

In Korean you don't use the name alone for someone older. If you are younger than Giselle, a woman would say unnie (언니) and a man would say noona (누나). If you are older, Giselle would be calling you that. Born the same year? You're 동갑 (dong-gap), and first names are fine.
